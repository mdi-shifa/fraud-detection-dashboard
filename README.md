# Real-Time Fraud Detection System with Explainable AI

## Project Overview

This project is an end-to-end AI-powered fraud detection system developed using Machine Learning, Explainable AI (SHAP), and Streamlit Dashboarding.

The system detects fraudulent financial transactions in real time and explains predictions using SHAP values.

---

## Features

- Fraud Detection using LightGBM
- Explainable AI with SHAP
- Risk Segmentation
- Interactive Streamlit Dashboard
- Plotly Visualizations
- Transaction Explorer
- Fraud Analytics

---

## Models Used

- LightGBM
- XGBoost
- Isolation Forest

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- SHAP
- Plotly
- Streamlit

---

## Dashboard Features

### Overview Page
- Total transactions
- Fraud detection rate
- Fraud amount analysis
- Interactive charts

### Transaction Explorer
- Explore transaction records
- Fraud probability analysis
- Risk tier identification

### SHAP Explainer
- Explainable AI interpretation
- Fraud feature analysis
